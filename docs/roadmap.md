# Broiler.JSeal Roadmap

## Current Status: 0.1.0-preview.1

Broiler.JSeal is extracted from Broiler.HtmlBridge as a standalone component.

### Included Deliverables
- [x] Engine-neutral contracts (`IJsRealm`, `JsValue`, `JsCapabilities`, `JsEngineRegistry`) in `Broiler.JSeal`
- [x] Zero references invariant maintained by the compiler
- [x] Broiler.JS provider (`Broiler.JSeal.BroilerJs`)
- [x] Broiler.VM provider (`Broiler.JSeal.Vm`)
- [x] Multi-engine conformance test suite (`Broiler.JSeal.Tests`)
- [x] Packaging automation (`eng/pack.ps1`) and multi-feed publishing workflows
